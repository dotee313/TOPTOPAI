# TOPTOPAI

تطبيق دردشة مع الذكاء الاصطناعي: ملف واحد `index.html` بلا تثبيت.

## التشغيل
- افتح `index.html` في المتصفح، أو فعّل GitHub Pages للمستودع (Settings ← Pages ← Deploy from branch ← main).
- من «الإعدادات» اختر المزوّد وضع مفتاح API.

## المزوّدون
OpenAI · OpenRouter · Groq · Google Gemini · Ollama (محلي) · أي خدمة متوافقة مع OpenAI.

المفتاح والمحادثات تُحفظ في المتصفح فقط.

## الخطوة التالية
دمج تطبيقات awesome-llm-apps كوكلاء جاهزين داخل الواجهة.
