# TOPTOPAI

تطبيق دردشة OpenCode: ملف واحد `index.html` بلا تثبيت، مع بناء أندرويد عبر Capacitor. يعمل بلا مفتاح API، ويضيف متصفحاً داخلياً ورؤية محلية للصور.

## التشغيل

- افتح `index.html` في المتصفح، أو ثبّت APK، ثم ابدأ الكتابة مباشرة.
- **لا يوجد مزوّد ولا مفتاح API تُدخله.** التطبيق مخصص لـ OpenCode ويعمل عبر نموذج مدمج متاح للجميع دون تسجيل.
- زر 🌐 يفتح متصفحاً داخلياً، وزر 👁️ يحلل صورة محلياً ويضع وصفها في حقل الإرسال.
- «الإعدادات» تحتوي فقط على وضع الوكيل وتعليماته الإضافية وشدة الإبداع وحد الطول والأدوات.

## النموذج المدمج

يستخدم التطبيق نقطة OpenAI المتوافقة في خدمة Pollinations العامة (`https://text.pollinations.ai/openai`) بالنموذج `openai-fast`، بلا مفتاح. الخدمة مجانية وقد تكون لها حدود استخدام أو توقف مؤقت؛ عندها يعرض التطبيق رسالة واضحة ويُعاد المحاولة تلقائياً عند توفرها. لا تُرسل أي مفاتيح لأن التطبيق لا يطلبها أصلاً.

النموذج نصي فقط؛ لذلك لا تُرسل الصور إليه كصورة خام. بدلاً من ذلك تُحلَّل الصورة على الجهاز ويُحقن تقريرها في الرسالة، فيقرأ الوكيل وصفاً نصياً واضحاً.

المحادثات وإعدادات الوكيل والبروكسي تُحفظ في المتصفح/الجهاز فقط.

## مساعد OpenCode

مساعد برمجة بأيقونة مخصصة وخيار مخصص، مستوحى من [anomalyco/opencode](https://github.com/anomalyco/opencode):

- **وضع التنفيذ (build):** ينفّذ على الكود المرفق ويعطي رداً موجزاً.
- **وضع التخطيط (plan):** خطة مرقّمة بالملفات المتأثرة والاختبارات قبل كتابة الكود.
- **وضع الاستكشاف (explore):** خريطة للبنية والاعتماديات مع مسارات الملفات وأرقام الأسطر.
- **نموذج مخصص:** من «الإعدادات ← خيارات OpenCode» يمكن تحديد نموذج برمجة مختلف يُستخدم فقط مع هذا المساعد.
- **اختصارات:** `/plan` و `/build` و `/explore` داخل المحادثة، أو زر الوضع في شريط المحادثة.
- **أدوات مساندة:** طقس، حاسبة، وقت، ويكيبيديا، **جلب صفحة ويب (`fetch_url`)**، التحقق من JSON، تعابير نمطية، وقائمة مهام.

> ملاحظة: هذا وكيل مستوحى من OpenCode يعمل مباشرة بلا مفتاح API؛ لا يُشغّل الـ CLI الخاص بـ OpenCode داخل WebView. الرؤية والتصفح محليان/داخليان ولا يضيفان مزوّداً ولا مفتاحاً.

## التصفح داخل التطبيق

- في APK: زر 🌐 يفتح نافذة متصفح مستقلة بـ WebView خاص، مع رجوع/تقدم/تحديث وشريط عنوان. طلباته تمرّ عبر `ProxyRouterState` نفسه، فتمرّ عبر البروكسيات التي عبّأها المستخدم.
- زر «⇪» داخل شريط المتصفح يضيف عنوان الصفحة ورابطها ونصها المرئي إلى حقل الإرسال، ليستطيع OpenCode العمل على ما قرأته.
- في المتصفح العادي (بدون APK): يظهر إطار احتياطي داخل نافذة، وبعض المواقع تمنع العرض داخل إطار؛ لذلك المتصفح الحقيقي هو تجربة APK.
- أداة `fetch_url` تجلب صفحة عامة وتحوّل HTML إلى نص مقروء؛ في APK تمرّ عبر الموجّه الأصلي، فتعمل حتى لو كانت استجابة الموقع لا تسمح بـ CORS.

## الرؤية المحلية للصور

زر 👁️ أو إرفاق صورة يُنتج تقريراً محلياً على الجهاز (بلا إنترنت ولا مفتاح) يشمل:

- أبعاد الصورة.
- أسماء ما يظهر فيها مع نسبة الثقة (وسم صور ML Kit، 400+ تصنيفاً).
- النص المطبوع إن وُجد (OCR).
- رموز QR والباركود وروابطها إن وُجدت.
- أبرز الألوان ونسبها التقريبية.

يُحقن التقرير في الرسالة قبل إرسالها، ويُحفظ ملخصه مع المحادثة على الجهاز. لا تُرسل الصورة الخام إلى النموذج النصي.

> لم تُضمَّن مكتبات Python مثل [ImageAI](https://github.com/OlafenwaMoses/ImageAI) ولا خوادم مثل [LocalAI](https://github.com/mudler/LocalAI) و[stable-diffusion-webui](https://github.com/AUTOMATIC1111/stable-diffusion-webui) لأنها تحتاج بيئة Python ونماذج ثقيلة لا تعمل داخل WebView. أُخذت فكرة «الرؤية السهلة على الجهاز» ونُفّذت كمكوّن أندرويد أصلي بـ ML Kit، وهو ما يحافظ على APK مستقل وبلا مفتاح.

## البروكسي (بديل VPN داخل التطبيق)

من زر «البروكسي» في القائمة الجانبية تعبئ قائمة بالبروكسيات، سطر لكل بروكسي:

```
host:port:user:pass:http
eu.proxy.net:3128:::http
socks.example.com:1080:user:pass:socks
```

- **في APK:** مكوّن أصلي (`ProxyRouter`) يوجّه طلبات التطبيق نفسه — بما فيها المتصفح الداخلي و`fetch_url` — عبر OkHttp، مع تناوب/تتابع عند الفشل/عشوائي/بروكسي واحد، ومصادقة `Proxy-Authorization`، وزر اختبار لكل بروكسي. صُمم بأسلوب [@mark2messmore/proxy-rotator](https://www.npmjs.com/package/@mark2messmore/proxy-rotator).
- **في المتصفح:** لا يستطيع JavaScript فتح اتصال بروكسي مباشر؛ لذلك تُستخدم بوابة تضع الرابط مكان `{url}` (مثلاً `https://your-proxy.example.com/?url={url}`).
- في APK لا يلزم تفعيل البروكسي لعمل الشبكة؛ الموجّه الأصلي يتصل مباشرة عند غياب البروكسيات، ويمرّ عبرها عند إدخالها وتفعيلها.
- لا يغيّر إعدادات نظام أندرويد، ولا يطلب صلاحية VPN، ولا يمرّر طلبات التطبيقات الأخرى. طلبات الواجهة المحلية (`https://localhost`) لا تُوجَّه عبر البروكسي.

تم لمس مفهوم التدفق الموحّد لواجهات النماذج في [vercel/ai](https://github.com/vercel/ai): الأدوات متعددة الخطوات، وأجزاء الملفات، وتدفق الاستجابة.
